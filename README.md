# homebrew-historyflow

The [Homebrew](https://brew.sh) tap for
[historyflow](https://github.com/jdf/historyflow-cli), a command-line program
that shows how a document came to be, version by version.

```sh
brew install jdf/historyflow/historyflow
```

`Formula/historyflow.rb` is written by `.github/workflows/update.yml` from a
release of [jdf/historyflow-cli](https://github.com/jdf/historyflow-cli), and
installs that release's binary for your platform.
